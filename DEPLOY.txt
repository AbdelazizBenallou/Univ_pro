===============================================================
  HOW TO DEPLOY A NEW VERSION
===============================================================

1. Push your code to GitHub (from your local machine)
   git add .
   git commit -m "vX.X.X - description"
   git push origin main

2. SSH into VPS
   ssh -i ~/.ssh/server2026-01-1 micro14@83.229.87.99

3. Pull latest code
   cd /var/www/Univ_pro
   git fetch origin
   git reset --hard origin/main

4. Install dependencies (if package.json changed)
   npm install

5. Build the project
   npm run build

6. Run database migrations (if schema changed)
   npx prisma migrate deploy

7. Restart the app
   pm2 restart backend-api --update-env

8. Verify it's running
   pm2 status
   curl -s http://localhost:3000/health

That's it. PM2 auto-restarts on crash and boots on server reboot.

===============================================================
  PM2 MANAGEMENT
===============================================================

  pm2 status                        # See running processes
  pm2 logs backend-api              # Tail logs
  pm2 logs backend-api --lines 50   # Last 50 lines
  pm2 restart backend-api           # Restart app
  pm2 stop backend-api              # Stop app
  pm2 delete backend-api            # Remove app
  pm2 flush backend-api             # Clear log files
  pm2 save                          # Save process list (for reboot)
  pm2 monit                         # Live monitoring dashboard

  PM2 auto-starts on reboot via systemd (pm2-micro14.service)

===============================================================
  TROUBLESHOOTING
===============================================================

  App won't start:
    pm2 logs backend-api --lines 30 --err
    # Check .env file, DB connection, MinIO

  Email not sending:
    echo '784512963' | sudo -S tail -20 /var/log/mail.log
    # Check Postfix status: sudo systemctl status postfix

  File upload/download broken:
    curl -s http://localhost:9000/minio/health/live
    # Check MinIO is running and bucket exists

  Out of memory:
    free -m
    pm2 status   # Check memory usage
    # Consider reducing max_memory_restart or adding swap

  Nginx not proxying:
    echo '784512963' | sudo -S nginx -t
    echo '784512963' | sudo -S systemctl restart nginx
